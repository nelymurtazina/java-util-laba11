# Text File Analyzer

Простое консольное приложение на Java для анализа текстовых файлов.

## Функциональность

- Подсчет количества строк, слов и символов в текстовом файле.
- Вывод статистики в консоль.
- Сохранение статистики в файл `stats.txt`.
